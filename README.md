# HR Analytics Dashboard

An interactive HR Analytics Dashboard built using Microsoft Excel to analyze employee data, attrition, workforce distribution, and compensation insights.

## Project Overview

This project analyzes employee data to identify key HR trends and workforce patterns.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Cleaning
- Data Analysis

## Dashboard Features

- Total Employees
- Attrition Count
- Attrition Rate
- Average Monthly Income
- Employees by Department
- Attrition by Department
- Gender Distribution
- Job Role Distribution
- Average Monthly Income by Department
- Work-Life Balance Distribution
- Overtime Distribution
- Education Field Distribution

## Key Skills Demonstrated

- Data Cleaning
- Data Analysis
- Data Visualization
- Excel PivotTables
- Dashboard Design
- Interactive Slicers
- HR Analytics

## Dataset

IBM HR Analytics Employee Attrition & Performance dataset.
